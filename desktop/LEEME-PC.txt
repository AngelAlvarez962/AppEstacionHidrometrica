HACKEANDO LAS INUNDACIONES - VERSION 0.2.0 PARA WINDOWS X64

Abre ABRIR-APP.cmd en la carpeta principal o ABRIR-ESTA-VERSION.cmd dentro de la version.
Los lanzadores usan el disco de cada PC. En una PC nueva copian el programa una sola vez.
Abrir directamente el EXE de la USB omite esta mejora y puede tardar mas.
Conserva todos los archivos de esta carpeta juntos.
No necesitas instalar Node.js para esta aplicacion compilada.

Esta es la version actual para pruebas; la version 0.1.0 es historica.
En la laptop de desarrollo la conexion ya esta configurada en el perfil privado de Windows.
En otra computadora sin conexion configurada puedes explorar la demo de kits.
No incluye la clave privada de Supabase; no compartas esa clave con compradores.

Incluye las presentaciones estacion + gateway, solo estacion y solo gateway.
Las estaciones de la misma cuenta pueden compartir su gateway.
Una estacion nueva exige seleccionar gateway y completar sus cuatro medidas.
Todavia falta probar el firmware y el gateway fisico con esta plataforma.
Los avisos por correo estan preparados, pero aun no hay proveedor configurado.
Los datos reales requieren Internet; no incluye el visualizador USB offline anterior.

Los archivos de desarrollo estan en Codigo\EstacionHidrometrica dentro de la USB.
Esta organizacion usa carpetas por version, sin ZIP.
Si Windows impide abrirlo, no desactives sus protecciones; esa PC requiere revisar la firma.
